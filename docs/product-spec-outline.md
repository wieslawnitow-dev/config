# План ТЗ: нишевой SEO-лидогенератор с конфигуратором

1. Назначение продукта
   - Продукт представляет собой продаваемый нишевой SEO-лидогенератор для локального или мульти-локального бизнеса, который продает изделия/услуги на заказ с расчетом по параметрам.
   - Продукт включает SEO-структуру, индивидуальный дизайн, подготовленный контент, конфигуратор/калькулятор стоимости, аналитику и инструменты донастройки конверсии.
   - Продукт не гарантирует позиции, трафик или лиды, но должен быть технически и структурно подготовлен для SEO-продвижения, измерения эффективности и последующей оптимизации.
   - Клиент после передачи должен иметь возможность самостоятельно поддерживать свой сайт: редактировать разрешенный контент, цены, настройки и пересобирать/деплоить проект без зависимости от продавца.
